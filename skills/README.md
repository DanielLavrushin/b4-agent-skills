# Skills

| Skill | Use it when |
| --- | --- |
| [b4-connect](b4-connect/SKILL.md) | the AI app shows no b4 tools, or b4's MCP server needs to be connected to an app |
| [b4-troubleshoot](b4-troubleshoot/SKILL.md) | a site, an app or b4 itself is not working, something broke after an update, or b4 clashes with the firmware or another tool |
| [b4-unblock-site](b4-unblock-site/SKILL.md) | a site the DPI blocks should work through b4: test, Discovery, apply, verify |
| [b4-proxy-routing](b4-proxy-routing/SKILL.md) | sites or devices should go through a VPN interface or a SOCKS5 upstream, or you need to know which set takes a connection |
| [b4-find-app-hosts](b4-find-app-hosts/SKILL.md) | you need to know which hosts and protocols an app on one device uses, and whether b4 handles them |
| [b4-report-issue](b4-report-issue/SKILL.md) | a problem should be reported on b4's GitHub with checked facts and no private data |

Each skill is one folder with a `SKILL.md`, and some have a `references/` folder for detail the skill opens on demand. Installation and the list of supported AI apps are in the [README](../README.md) ([на русском](../README_ru.md)).
