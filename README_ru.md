# Навыки b4 для ИИ-ассистентов

[English version](README.md)

Навыки для ИИ-ассистентов, которые помогают проверять и настраивать [b4](https://github.com/DanielLavrushin/b4) на вашем роутере через встроенный MCP-сервер b4. Они для тех, кто пользуется b4. Для работы над кодом b4 см. [репозиторий b4](https://github.com/DanielLavrushin/b4).

Навык - это набор инструкций в открытом формате [Agent Skills](https://agentskills.io/). Ассистент загружает его, когда запрос подходит, и следует ему, пока работает с инструментами b4.

## Навыки

| Навык | Что делает |
| --- | --- |
| [b4-troubleshoot](skills/b4-troubleshoot/SKILL.md) | Выясняет, почему не работает сайт, приложение или сам b4: сайт не открывается, Дискавери ничего не находит, проблемы с Telegram или YouTube, возможность показана как недоступная, что-то сломалось после обновления, b4 конфликтует с функциями прошивки или другим прокси. |
| [b4-proxy-routing](skills/b4-proxy-routing/SKILL.md) | Настраивает или чинит сеты, которые отправляют сайты или устройства через VPN-интерфейс или SOCKS5-прокси, и определяет, какой сет забирает соединение: трафик идёт напрямую, у соединений через прокси нет имени сайта, нужно «всё, кроме этих сайтов», DNS ломается после включения сета маршрутизации. |

Оба навыка велят ассистенту:

- сначала читать состояние b4: статус, диагностику, журнал ошибок, сеты, последние соединения;
- смотреть каждую настройку в описаниях настроек самого b4, а не угадывать по названию;
- сравнивать установленную версию b4 с [журналом изменений](https://github.com/DanielLavrushin/b4/blob/main/changelog_ru.md) и указывать на исправление в более новом выпуске;
- говорить, что сайт открывается, только после успешной проверки этого сайта средствами b4;
- проверять сайт или менять настройку только по вашей просьбе и когда в b4 включён соответствующий переключатель, после изменения читать сохранённое значение и отменять своё последнее изменение средствами b4;
- спрашивать, что ещё работает на роутере, когда признаки указывают за пределы b4, а не гадать.

## Перед началом

Навыкам нужен MCP-сервер b4, подключённый к вашему ИИ-приложению. Настройка занимает несколько минут: [Подключение ИИ-ассистента](https://docs.b4core.app/ru/docs/settings/mcp/).

По умолчанию ассистент может только читать. Два переключателя на карточке **MCP-сервер** в разделе **Настройки > Интеграции** веб-интерфейса b4 разрешают больше:

- **Разрешить изменение настроек**: ассистент может менять настройки и сеты.
- **Разрешить активные проверки**: ассистент может проверять с роутера, открывается ли сайт, и запускать Дискавери.

После включения переключателя переподключите ИИ-приложение к MCP-серверу, чтобы оно получило новые инструменты.

| Приложение | Навыки | Примечания |
| --- | --- | --- |
| Claude Code | да | Проверено. Установка через skills CLI или как плагин. |
| Claude Desktop | да | Вкладка Code работает как Claude Code. Не проверялось. |
| claude.ai | нет | Его коннекторы подключаются из облака Anthropic и не достают до роутера в домашней сети. |
| Codex CLI, Gemini CLI, Cursor, VS Code с GitHub Copilot | да | Эти приложения загружают Agent Skills; установка через skills CLI. С b4 не проверялось. |
| ChatGPT | нет | Свои MCP-подключения ChatGPT делает из облака OpenAI, и им нужен публичный HTTPS-адрес или туннель OpenAI, поэтому роутер в домашней сети недоступен. |
| LM Studio, Jan | нет | Они не загружают навыки. Текст SKILL.md можно вставить в системный промпт или инструкции ассистента. В проверке маленькая локальная модель (llama3.2, 3B) не справилась с этими задачами ни с ним, ни без него. |
| Ollama | нет | Сама по себе Ollama не подключается к MCP-серверам. |
| Встроенные ИИ-пояснения b4 | нет | Они объясняют настройки в веб-интерфейсе и не пользуются инструментами b4. |

## Установка

### Через skills CLI

Нужен Node.js. Запустите в папке, которую открываете в ИИ-приложении, или добавьте `-g`, чтобы установить для своего пользователя:

```sh
npx skills add DanielLavrushin/b4-agent-skills
```

Команда спросит, какие навыки и для каких приложений установить. Чтобы ответить заранее, укажите приложение, например:

```sh
npx skills add DanielLavrushin/b4-agent-skills --skill '*' -a claude-code -y
```

Другие имена приложений: `codex`, `gemini-cli`, `cursor`, `github-copilot`.

### Как плагин Claude Code

В Claude Code:

```text
/plugin marketplace add DanielLavrushin/b4-agent-skills
/plugin install b4@b4-agent-skills
```

Или из терминала:

```sh
claude plugin marketplace add DanielLavrushin/b4-agent-skills
claude plugin install b4@b4-agent-skills
```

## Как пользоваться

Спрашивайте своими словами, например «после обновления b4 перестал открываться discord.com» или «пусти youtube.com через интерфейс wg0». Ассистент сам загрузит подходящий навык. Чтобы вызвать навык напрямую в Claude Code, введите `/b4-troubleshoot` или `/b4-proxy-routing` (с плагином: `/b4:b4-troubleshoot`, `/b4:b4-proxy-routing`).

Если проблема не решилась, ассистент перечислит, что приложить к сообщению о проблеме: см. [Сообщение о проблеме](https://docs.b4core.app/ru/docs/troubleshooting/reporting/).

## Участие

Каждый навык - это папка в [`skills/`](skills/) с файлом `SKILL.md`. Во frontmatter только ключи [спецификации Agent Skills](https://agentskills.io/specification) (`name`, `description`, необязательный `compatibility`), а `name` совпадает с именем папки. Навык не утверждает о настройке b4 ничего, что не подтверждено описаниями настроек самого b4 или его исходным кодом, и никогда не обещает, что сайт заработает.
